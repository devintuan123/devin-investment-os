# Developer Role

## Role

- Implements clean, maintainable code.
- Avoids duplicate logic.
- Adds reusable utilities.
- Keeps providers read-only.

## Checklist

- No duplicated translation or table formatting logic.
- Shared UI components are used across pages.
- No hard-coded UI strings where i18n should be used.
- No crashes when provider data is missing.
- Compile check passed.
- Existing tests still pass.

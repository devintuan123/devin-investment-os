# UI/UX Designer Role

## Role

- Reviews layout, readability, page hierarchy, and mobile usability.

## Checklist

- Sidebar is consistent across all pages.
- Language switch appears on every page.
- Primary metrics are visible without excessive scrolling.
- Tables have readable column names.
- Warnings are noticeable but not overwhelming.
- Chinese layout does not look broken.
- English layout does not mix Chinese.

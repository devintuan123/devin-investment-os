# Project Manager Role

## Role

- Owns task breakdown.
- Defines scope.
- Prevents Codex from stopping early.
- Ensures final report is honest.
- Confirms Definition of Done.

## Checklist

- Is the task scope fully completed?
- Did Codex continue automatically to the next planned phase if instructed?
- Are blockers clearly stated?
- Are files changed listed?
- Are tests actually run?
- Is the user protected from manual checking burden?

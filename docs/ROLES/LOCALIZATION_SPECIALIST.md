# Localization Specialist Role

## Role

- Owns Traditional Chinese and English bilingual quality.
- Checks UI strings, table headers, table cell values, reports, and Telegram text.

## Checklist

- Traditional Chinese uses Taiwan financial terminology.
- English is clean financial dashboard English.
- Table headers are translated.
- Table cell labels are translated.
- Action labels are translated.
- Risk labels are translated.
- Status labels are translated.
- Provider names and tickers remain unchanged.
- No mixed-language UI except approved technical identifiers.
- `audit_i18n` and `audit_table_i18n` pass.

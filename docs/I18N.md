# Internationalization

## Supported languages

- Traditional Chinese (`zh`)
- English (`en`)

Default language: Traditional Chinese.

## Where translations live

Translation keys live in:
`utils/i18n.py`

Core helpers:
- `get_lang()`
- `set_lang(lang)`
- `t(key)`
- `translate_action_label(label)`
- `translate_risk_label(label)`
- `translate_regime(label)`

## How to add translations

1. Add a stable key to `TRANSLATIONS["en"]`.
2. Add the Traditional Chinese translation to `TRANSLATIONS["zh"]`.
3. Use `t("key")` in Streamlit pages.
4. For action labels, add a mapping to `ACTION_LABEL_KEYS`.
5. For risk labels, add a mapping to `RISK_LABEL_KEYS`.

## UI rule

Avoid mixing languages in one UI mode except for tickers, provider names, API names, and market symbols.

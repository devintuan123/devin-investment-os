# Definition of Done

A task is not done until:

- Code compiles.
- Relevant tests pass.
- i18n audit passes if UI changed.
- Table i18n audit passes if tables changed.
- No secrets are staged.
- No trading functionality added.
- App deploys if app behavior changed.
- Health check passes when deployment is required.
- Final report includes commit hash.
- Role-based review passes.

## Bilingual UI Tasks

- Page labels translated.
- Buttons translated.
- Warnings translated.
- Table headers translated.
- Table cell labels translated.
- Telegram/report text translated if affected.
- Snapshots generated.

## Financial Logic Tasks

- No "Buy Now".
- No execution language.
- Risk warnings included.
- Data source confidence shown.
- Delayed data clearly marked.
